# แผนงานอาจารย์ · ปีงบ 2570

แดชบอร์ดติดตามงานตามแบบประเมินอาจารย์ มรภ.สวนสุนันทา ปีงบประมาณ 2570 (ภาคเรียน 2/2569 – 1/2570)

- **ต้องทำตอนนี้** — คำนวณจากวันที่ปัจจุบันอัตโนมัติ (เลยกำหนด / ช่วงนี้ / ใกล้ถึง)
- **คะแนนประเมิน** — ติ๊กและกรอกผล เพื่อดูคะแนนคาดการณ์เทียบเป้า 65
- **เอกสาร 9 องค์ประกอบ + On demand** — ติดตามรายวิชา
- **ไทม์ไลน์** — วันสำคัญจากปฏิทินวิชาการ 2569 และกิจกรรมบังคับ
- **การเตือน** — แจ้งเตือนผ่านเบราว์เซอร์เมื่อเปิดหน้า และปุ่ม "เพิ่มลงปฏิทิน (.ics)" สำหรับให้มือถือเตือนล่วงหน้า

## แก้ไขกำหนดการ
